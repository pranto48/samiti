# Somiti (অগ্রযাত্রা সমবায় সমিতি) - ক্লাউড হিসাব সফটওয়্যার

একটি আধুনিক, সুরক্ষিত ও রিয়েলটাইম সমবায় সমিতি পরিচালনা এবং হিসাব-নিকাশ ওয়েব প্ল্যাটফর্ম। এটি **Firebase Firestore** এবং **Firebase Authentication** দিয়ে সংযুক্ত এবং সরাসরি **Vercel** এ সহজে হোস্ট করার জন্য তৈরি।

---

## ✨ প্রধান সুবিধাসমূহ (Key Features)

1. **ড্যাশবোর্ড সামারি (Dashboard Overview)**:
   - সর্বমোট সঞ্চয়, মোট বিনিয়োগকৃত জামানত, মোট অর্জিত মুনাফা ও তহবিলে অবশিষ্ট নগদ টাকা (Cash in Hand)।
   - মোট সক্রিয় সদস্য সংখ্যা, জরিমানা ও ফি আদায় এবং প্রতি শেয়ারে বর্তমান প্রস্তাবিত লভ্যাংশ স্বয়ংক্রিয় ক্যালকুলেশন।

2. **সদস্য ব্যবস্থাপনা ও লেজার (Member Ledger)**:
   - সদস্য তালিকা, শেয়ার সংখ্যা ও লাইভ সঞ্চয় ব্যালেন্স।
   - সদস্যের নাম, আইডি বা মোবাইল দিয়ে তাৎক্ষণিক সার্চ।
   - প্রতিটি সদস্যের ব্যক্তিগত খতিয়ান ও জমার বিবরণী।

3. **সঞ্চয় ও কিস্তি আদায় (Collections & Money Receipt)**:
   - সদস্য নির্বাচন করলে শেয়ার অনুপাতে স্বয়ংক্রিয়ভাবে কিস্তির টাকা সাজেশন।
   - কিস্তি জমার পর সঙ্গে সঙ্গে অফিসিয়াল প্রিন্ট-রেডি **মানি রসিদ (Deposit Voucher)** তৈরি (জমা প্রদানকারী ও আদায়কারীর স্বাক্ষর স্থানসহ)।

4. **বিনিয়োগ ও লভ্যাংশ বণ্টন (Investments & Dividends)**:
   - জমি রেহান, দোকান বন্ধক ও কৃষি বিনিয়োগ ট্র্যাকিং।
   - বিনিয়োগ থেকে অর্জিত লাভ (দোকান ভাড়া, ফসল বিক্রি)।
   - শেয়ার অনুপাতে স্বয়ংক্রিয় মুনাফা বণ্টন ক্যালকুলেটর।

5. **আয় ও ব্যয় হিসাব (Expenses & Other Income)**:
   - স্ট্যাম্প, পরিবহন, আপ্যায়ন ও ব্যাংক চার্জ ইত্যাদির দৈনিক খরচ সংরক্ষণ।
   - বিবিধ আয় ও ব্যাংক মুনাফা সংরক্ষণ।

6. **পূর্ণাঙ্গ আর্থিক প্রতিবেদন (Audit & Financial Statements)**:
   - তহবিলের উৎস (মোট আদায় ও আয়) বনাম তহবিলের প্রয়োগ (সম্পত্তি, বিনিয়োগ ও ব্যয়)।
   - সদস্যভিত্তিক ইকুইটি ও ব্যালেন্স বিবরণী (প্রিন্ট ফরম্যাট)।

7. **ক্লাউড সিঙ্ক ও ব্যাকআপ**:
   - ফায়ারবেস ক্লাউড ডেটাবেসের সাথে রিয়েলটাইম সিঙ্ক।
   - ১-ক্লিকে সম্পূর্ণ ডেটা JSON ফাইল হিসেবে অফলাইন ব্যাকআপ ডাউনলোড।

## 🚀 Vercel-এ ওয়েবসাইট পাবলিশ করার নিয়ম (Deploy to Vercel)

### পদ্ধতি ১: GitHub এর মাধ্যমে (সবচেয়ে সহজ ও অটোমেটিক)
1. এই প্রোজেক্ট ফোল্ডারটি আপনার GitHub রিপোজিটরিতে পুশ (Push) করুন:
   ```bash
   git add .
   git commit -m "Initial commit for Somiti web app"
   git push origin main
   ```
2. [Vercel.com](https://vercel.com)-এ লগইন করে **"Add New Project"** এ ক্লিক করুন।
3. আপনার GitHub রিপোজিটরিটি সিলেক্ট করুন।
4. Framework Preset হিসেবে **"Other"** থাকবে এবং Root Directory `./` থাকবে।
5. **"Deploy"** বাটনে ক্লিক করুন! কয়েক সেকেন্ডের মধ্যে আপনার ওয়েবসাইট লাইভ হয়ে যাবে।

### পদ্ধতি ২: Vercel CLI এর মাধ্যমে (টার্মিনাল থেকে)
1. টার্মিনালে Vercel CLI ইনস্টল করুন (যদি না থাকে):
   ```bash
   npm i -g vercel
   ```
2. প্রোজেক্ট ফোল্ডারে কমান্ড দিন:
   ```bash
   vercel
   ```
3. প্রম্পট অনুসরণ করে এন্টার চাপুন। কিছুক্ষণের মধ্যে প্রোডাকশন ইউআরএল পেয়ে যাবেন:
   ```bash
   vercel --prod
   ```

## 🔒 Firebase Security Rules (নিয়মাবলী)

আপনার ফায়ারবেস কনসোলে ([Firebase Console](https://console.firebase.google.com/project/somiti-956b5/firestore/rules)) গিয়ে Firestore Database Rules অপশনে নিচের রুলটি সেভ করে দিন:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      // যে কেউ হিসাব দেখতে পারবে, কিন্তু ডাটা পরিবর্তন করতে অ্যাডমিন লগইন থাকতে হবে
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
```
*(টেস্টিং কালীন সময়ে যদি লগইন ছাড়া এন্ট্রি টেস্ট করতে চান, তাহলে `allow read, write: if true;` সাময়িকভাবে রাখতে পারেন।)*
